Student Performance Prediction System 🎓

📌 About the Project

The Student Performance Prediction System is a Python-based mini project designed to analyze and predict students' academic performance based on their study habits and academic details.

The project helps understand how factors such as study hours, attendance, and previous academic performance can influence a student's overall results.

It provides a simple, user-friendly interface where users can enter student details and view their predicted performance.

✨ Features

- Enter student academic details.
- Record study hours and attendance.
- Analyze student performance.
- Predict expected academic performance.
- Display results based on user input.
- Simple and easy-to-use interface.

🛠️ Technologies Used

- Functions
- Conditional Statements
- Loops
- Lists and Dictionaries
- File Handling
- Exception Handling

▶️ How to Run the Project

1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file.
